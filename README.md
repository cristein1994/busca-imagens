# BOYRADAR

Buscador de **garotos de programa / acompanhantes masculinos** (adultos **21+**).

SPA Vite + React + TypeScript. Catálogo seed com anúncios públicos + filtros locais. Não intermedia pagamento nem atendimento.

## Funcionalidades

- Age gate 21+
- **Amigo Safado**: chat gay puto que recomenda GP, monta zap e pede scrap
- **Scrap web** (dev): proxy Vite → BOY.gp / Garoto Com Local; se Cloudflare bloquear, merge do snapshot `public/scraped.json`
- Filtros: cidade, posição (só ativo / ativo / versátil…), cm mínimo, preço, atende homens, com local
- Ordenação por pau, preço, idade, nome
- Favoritos (`localStorage`)
- Detalhe com WhatsApp pré-preenchido + link da fonte
- Default: Uberaba · só ativo · 17 cm+

## Rodar

```bash
npm install
npm run dev
```

## Aviso

Conteúdo adulto. Confirme idade/posição com o anunciante. Não pague adiantado.
